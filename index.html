ข้อ 2Basic Instruction Cycle

วิธีทำแบบแผงต่อเนื่อง อ่านจากซ้ายไปขวา แล้วบนลงล่าง. ทุกคำสั่งใช้ 2 แผง: Fetch ดึงคำสั่งเข้า IR แล้ว Decode + Execute พร้อม PC = PC+1. ช่องสีเหลืองคือค่าที่เพิ่งเปลี่ยน ลูกศรสีน้ำเงินคือทิศที่ข้อมูลไป.

โจทย์

หน่วยความจำ (Address 3 หลัก, ค่า 4 หลัก ฐาน 16, เว้นค่าว่างไว้ = ช่องว่าง)
LOAD และ STORE ย้ายข้อมูลอย่างไร

จำ!! ขั้นตอนของ 1 คำสั่ง

  1. Fetch: ดูตำแหน่งที่ PC ชี้ แล้วดึงคำสั่งตำแหน่งนั้นมาไว้ที่ IR (ทับตัวเดิม)
  2. Decode: ดู Opcode (เลขหลักแรกของคำสั่ง) และ Address (เลข 3 หลักหลัง)
  3. Execute: ทำตาม Opcode แล้ว PC = PC + 1
Opcodeฐาน 2ความหมาย
10001Load AC from Memory: เอาข้อมูลที่ Address มาไว้ที่ AC
20010Store AC to Memory: เอาค่าใน AC ไปเก็บที่ Address
50101Add AC from Memory: AC + ข้อมูลที่ Address แล้วเก็บที่ AC

คำสั่งยาว 16 บิต: Opcode 4 บิต (บิต 0–3) + Address 12 บิต (บิต 4–15). ค่าทุกช่องเป็นเลขฐาน 16 บวกกันด้วยฐาน 16!! ตอน Add ข้อมูลใน Memory ไม่หาย

ข้อ 3Shifter

ใส่เลขฐาน 2 แล้วดูผลของ SHL, SHR, ROL, ROR เทียบกันได้เลย. สีแดง = บิตที่ถูกตัดทิ้ง, สีเขียว = บิตที่ใส่ใหม่, สีน้ำเงิน = บิตที่หมุนวน.

เทียบกัน

โน้ต: อาจเหมือนกันหรือไม่เหมือนกันก็ได้ ขึ้นกับบิตที่ถูกตัด อย่าฟันธงว่าเหมือนกัน

  • SHL เลื่อนซ้าย: ตัดตัวซ้ายสุดทิ้ง แล้วใส่ 0 ทางขวา
  • SHR เลื่อนขวา: ตัดตัวขวาสุดทิ้ง แล้วใส่ 0 ทางซ้าย
  • ROL หมุนซ้าย: ตัวซ้ายสุดไปต่อทางขวา (ไม่มีบิตหาย)
  • ROR หมุนขวา: ตัวขวาสุดไปต่อทางซ้าย (ไม่มีบิตหาย)
  • Arithmetic shift right (ในสไลด์): เหมือน SHR แต่เติมบิตซ้ายสุด (เครื่องหมาย) แทน 0
  • รูป 4.2 ในสไลด์แสดง Rotate Left แบบผ่าน Carry (C): บิตซ้ายสุดเข้า C และ C เข้าทางขวา. ถ้าโจทย์ให้ Carry มาให้ทำตามนั้น

คำสั่ง 0, 1, 2, 3 Address

โจทย์เดียวกันจากสไลด์: Y = (A − B) / (C + D * E). เลือกชนิดเพื่อดูโปรแกรมและความหมายทีละบรรทัด.

เก็บตก

ข้อมูลในคำสั่ง (Instruction Contents)

  • Op Code บอกว่าทำอะไร (Binary, ฟิลด์แรก)
  • Source operand reference ที่เก็บข้อมูลที่จะนำเข้ามาทำงาน
  • Result reference ที่เก็บผลลัพธ์
  • Next instruction reference ตำแหน่งคำสั่งถัดไป (ส่วนใหญ่ไม่ระบุในคำสั่ง)

  • Logic AND OR NOT XOR, Shift, Rotate
  • Data movement MOVE, PUSH-POP, LOAD-STORE
  • I/O Control, Test, Read (IN), Write (OUT)

Flag: Carry · Borrow · Overflow · Underflow · Zero · Negative

Stack (LIFO) ลองกด

ขนาด 5 ช่อง เริ่มต้นเหมือนรูป 4.4 ในสไลด์: 5, 9, 8 และ SP = 3

Push: SP + 1 แล้วเก็บค่า · POP: X = ST(SP) แล้ว SP − 1 · ล้นคือ Stack Overflow, ว่างแล้ว POP คือ Stack Underflow

Big / Little Endian

Big Endian เก็บไบต์หลักมาก (MSD) ไว้ Address ต่ำก่อน, Little Endian เก็บหลักน้อย (LSD) ไว้ Address ต่ำก่อน. Motorola = Big, Intel = Little. ถ่ายโอนข้ามตระกูลต้องแปลงข้อมูลก่อน.

Control Operation

  • Branch / Jump กระโดดไป Address ที่กำหนด ส่วนมากมีเงื่อนไข: BRP (บวก), BRN (ลบ), BRZ (ศูนย์), BRO (Overflow), BRE R1,R2,X (R1 = R2)
  • Skip ข้าม 1 คำสั่ง ไม่ต้องใช้ Address ปลายทาง เช่น ISZ R1 = เพิ่มค่า R1 แล้วข้ามถ้าเป็น 0 (ใช้ทำ loop)
  • Subroutine call CALL ไปโปรแกรมย่อย จบด้วย Return. CPU เก็บตำแหน่งกลับไว้ใน Stack จึงเรียกซ้อนกัน (Nested) ได้
  • เหตุผลที่ต้องมี: ทำ loop, ตัดสินใจตามเงื่อนไข, แบ่งโปรแกรมใหญ่เป็นโมดูล และประหยัดเนื้อที่หน่วยความจำ

I/O Instruction

  • Control สั่งอุปกรณ์ให้ทำงาน เช่น เทปถอยหลัง
  • Test ตรวจสถานะ I/O Module และอุปกรณ์ (Power On? เสร็จหรือขัดข้อง?)
  • Read / IN I/O Module รับข้อมูลจากอุปกรณ์มาพักใน Data register แล้ว CPU ขอให้วางบน Data Bus เพื่อรับเข้า CPU
  • Write / OUT CPU ส่งข้อมูลผ่าน Data Bus ไปพักใน Data register ของ I/O Module เมื่ออุปกรณ์พร้อมจึงรับไป

Data movement

MOVE String ต้องบอก Source Address, ความยาว L และ Destination Address
